# Avaliacao Semestral - Padroes de Projetos

Projeto em Java (somente biblioteca padrao). Precisa do JDK 17 ou superior.

## Questao 1 - Provisionamento Multinuvem

Padroes: **Abstract Factory** e **Singleton**.

Para executar, entre na pasta `questao1/src` e rode:

```
javac *.java
java Main
```

## Questao 2 - Casa de Leiloes Online

Padroes: **Observer**, **Strategy** e **Decorator**.

Para executar, entre na pasta `questao2/src` e rode:

```
javac *.java
java Main
```

## Diagramas

Os diagramas de classe (PlantUML) ficam na pasta `diagrama` de cada questao.
